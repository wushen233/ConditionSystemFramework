# Temporary Repair Menu

`JuryRiggingMenu.fla` is the authoritative Adobe Animate project for the
temporary repair/Jury Rigging menu. `JuryRiggingMenu.as` is its AS3 document
class, and the `Shared/` plus `scaleform/gfx/` files are the small Scaleform
compatibility classes required to publish this FLA without reaching into the
unrelated `HUDMenu` project directory.

The project publish manifest stages the result as
`data/Interface/JuryRiggingMenu.swf`. `JuryRiggingMenu.legacy.as2` is retained
for historical comparison and is not a publish input.
