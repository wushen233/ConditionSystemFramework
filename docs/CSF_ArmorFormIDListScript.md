# 通用 FormID List 批量工具

脚本位置：`vendor/tools/xedit/Edit Scripts/CSF_AddSelectedRecordsToFormIDList.pas`

这个脚本不绑定“服装”“护甲”或某个固定分类。分类名称和归属完全由使用者选择的 FormID List 与 CSF JSON 决定，因此也可以给其他模组作者作为通用工具使用。

## 目标列表

运行脚本后先选择目标方式：

1. 首先会打开脚本的目标插件选择窗口。可勾选已加载插件，或勾选 `<new file>` 进入 xEdit 的新建插件流程。
2. 然后会列出目标插件内已有的 FormID List；勾选 `<new FormID List>` 可在该插件中新建列表，再输入其 EditorID。

目标插件必须是可编辑插件。原版 `Fallout4.esm` 等主文件只能作为来源扫描，不能作为目标写入。

## 来源记录

来源方式由 xEdit 当前选择自动判断：

1. 选中主记录或记录组：把其中记录直接加入目标列表，不限制记录类型。适合已经在 xEdit 中筛选好的记录。
2. 选中插件：先列出该插件可扫描的记录类型，再选择一个或多个类型；随后逐类列出具体记录供多选。可扫描类型为 `KYWD`、`OMOD`、`FLST`、`WEAP`、`ARMO`。

直接加入会在 xEdit 的 `Process` 阶段立刻写入，不依赖脚本结束后的回调。没有选中任何记录时，脚本会在结束阶段弹出来源插件选择窗口。

选中整个插件而不是具体记录时，脚本把它当作扫描来源，不会把插件本身当成 FormID List 成员。

## 写入规则

- 已存在的 FormID 不会重复加入。
- 添加第三方记录时，会自动为目标插件补充对应 master。
- 现有列表内容不会被删除或重排。
- 最后会输出 `added`、`duplicates`、`ignored` 统计。

## 推荐用法

批量建立服装/护甲分类时：选择用于保存 CSF 分类的插件，创建或选择一个分类 FormID List；然后选中原版或模组插件，使用扫描模式筛选 `ARMO` 记录，多选后写入。武器分类同理，扫描时选择 `WEAP`；需要补充关键字、改装或嵌套列表时，选择对应的 `KYWD`、`OMOD` 或 `FLST`。
