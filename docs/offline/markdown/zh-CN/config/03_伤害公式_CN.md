# 伤害公式模块

运行时目录：

```text
Data/F4SE/Plugins/ConditionSystemFramework/Durability/DamageFormula/
```

当前 loader 会读取目录中的 `DamageFormula` 对象。实际读取的字段只有下面七个：

```jsonc
{
  "DamageFormula": {
    "enabled": true,
    "baseHardness": 1.0,
    "glanceThreshold": 0.3,
    "glanceMultiplier": 0.1,
    "scratchThreshold": 0.7,
    "scratchMultiplier": 0.4,
    "durabilityDamageConstant": 0.15
  }
}
```

## 计算路径

命中数据可用时，CSF 先计算：

```text
blockPercentage = totalResisted / totalRawDamage
```

然后根据拦截率选择磨损阶段：

| 条件 | 阶段 | 使用倍率 |
|---|---|---|
| `blockPercentage >= glanceThreshold`，或 >= 0.90 | 完美防御/装甲全额承受冲击 | `glanceMultiplier` |
| `blockPercentage <= scratchThreshold`，或 <= 0.20 | 护甲被贯穿/未起到有效拦截 | `scratchMultiplier` |
| 其他情况 | 常规拦截吸收 | `1.0` |

命中数据可用时的基础耐久损耗为：

```text
totalResisted
  * durabilityDamageConstant
  * 阶段倍率
  * 内外层倍率
  * 动力甲框架倍率
  * 弹药 armorDamageMult
```

没有命中数据时，CSF 使用有效抗性计算硬度：

```text
hardness = max(1.0, baseHardness + effectiveResist)
durabilityCost = (totalImpact / hardness)
                 * durabilityDamageConstant
                 * 内外层倍率
                 * 动力甲框架倍率
                 * 弹药 armorDamageMult
```

之后还会套用护甲 OMOD、技能修正、`fArmorWearMultiplier`，最低损耗会被钳制到 0.01。

## 字段说明

| 字段 | 作用 |
|---|---|
| `enabled` | 当前会被 loader 读取，但计算路径没有用它作为旁路开关 |
| `baseHardness` | 无命中数据路径的基础硬度 |
| `glanceThreshold` | 进入低损耗拦截阶段的上限阈值 |
| `glanceMultiplier` | 低损耗拦截阶段倍率 |
| `scratchThreshold` | 进入穿透/低拦截阶段的阈值 |
| `scratchMultiplier` | 穿透/低拦截阶段倍率 |
| `durabilityDamageConstant` | 伤害转换为耐久损耗的总常数 |

阈值是比例值，通常在 `0.0` 到 `1.0` 之间。不要把它们写成百分数 `30`、`70`。

## 当前文件中的 ratingMultipliers

当前示例 `01_DamageFormula.json` 还包含 `ratingMultipliers` 及若干伤害类型说明，但当前 `ProfileManager.cpp` 的 loader 没有读取这个对象，`DamageFormulaConfig` 也没有对应字段。因此目前修改 `ratingMultipliers` 不会改变运行时结果。

这部分保留在示例文件中是历史设计痕迹，不能当作当前可配置功能。若以后启用伤害类型硬度倍率，需要同时修改 C++ 数据结构、loader、计算路径和文档。

## 与 MCM 的关系

- 当前源码虽然读取 `enabled`，但计算路径没有根据它跳过公式；它目前不能作为关闭开关。
- `bEnableArmorCondition` 控制护甲耐久系统总开关。
- `bArmorConditionAffectsResistance` 控制护甲当前耐久是否影响游戏抗性。
- `fArmorWearMultiplier` 是公式结果之后的总磨损倍率。

JSON 负责公式常数，MCM 负责用户运行时开关和总倍率；两者不是同一个配置层。
