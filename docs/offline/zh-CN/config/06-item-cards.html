物品卡片模块

配置文件：

Data/F4SE/Plugins/ConditionSystemFramework/ItemUICards.json

该文件只控制 IIF 物品卡片里的 CND 行位置，不控制 HUD CND 小部件，也不决定物品是否进入耐久系统。

当前结构

{
  "ItemUICards": {
    "CND": {
      "priority": 0,
      "anchorTarget": "$ammo",
      "anchorMode": "after",
      "fallbackAnchorTarget": "TOP",
      "fallbackAnchorMode": "after"
    }
  }
}

字段：

| 字段 | 作用 | |---|---| | priority | 多个卡片行注册时的排序优先级 | | anchorTarget | 首选锚点，例如 $ammo | | anchorMode | 相对首选锚点插入的位置，当前使用 after | | fallbackAnchorTarget | 首选锚点不存在时使用的锚点 | | fallbackAnchorMode | 备用锚点的插入位置 |

常见调整

若某个物品卡片没有弹药行，CSF 会使用 fallbackAnchorTarget。因此调整 CND 行位置时优先修改锚点，不要在 SWF 中写死坐标。

这个模块依赖 Item Integration Framework 的物品卡片接口。IIF DLL 没有加载时，CND 行不会注册；这和工作台维修按钮以及 HUD 小部件是不同的接口问题。
