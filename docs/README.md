# Condition System Framework Docs

中文配置文档已经按当前运行时模块完全拆分：

- `Config_Guide_CN.md`：中文入口索引。
- `config/00_配置总览_CN.md`：配置根目录、FormID、依赖和加载模型。
- `config/01_分类_CN.md`：武器/护甲分类、Pipe 标记和精确排除。
- `config/02_耐久消耗_CN.md`：基础 Profile、弹药、OMOD、分类倍率和技能磨损。
- `config/03_伤害公式_CN.md`：护甲伤害到耐久损耗的公式。
- `config/04_维修_CN.md`：Jury Rigging、OverRepair 和 Repair Kits。
- `config/05_战利品_CN.md`：随机初始耐久和技能奖励。
- `config/06_物品卡片_CN.md`：IIF CND 卡片行锚点。
- `config/07_Provider选择_CN.md`：Provider 合并、单选和 canonical 文件名。
- `config/08_MCM与INI_CN.md`：MCM 用户配置和运行时 INI。

英文配置文档已经同步：

- `Config_Guide_EN.md`：英文入口索引。
- `config/00_Configuration_Overview_EN.md` 到 `config/08_MCM_and_INI_EN.md`：英文模块文档。
